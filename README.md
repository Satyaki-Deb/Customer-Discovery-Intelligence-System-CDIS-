Customer Discovery Intelligence System (CDIS) is a Python-based business intelligence tool designed to support startup customer discovery and market validation.

The system allows users to record customer interviews, store and retrieve interview data, analyze market insights, identify Ideal Customer Profiles (ICPs), rank prospects based on attractiveness, and generate actionable recommendations for follow-up.

Key features include:

• Interview data collection and storage
• Market insights and summary statistics
• ICP scoring and classification engine
• Prospect prioritization and ranking
• Recommendation generation for founder follow-up
• Executive summary reporting
• Explanation engine highlighting the factors behind prospect prioritization

The project was built using core Python concepts including functions, dictionaries, file handling, loops, conditionals, lists, sorting, and modular program design.

The objective was to create a practical decision-support system that helps startups identify and prioritize promising customer opportunities while developing business-oriented programming skills.
